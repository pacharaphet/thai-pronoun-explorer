# Thai Pronoun Explorer

Learn Like Luke interactive Thai pronoun reference. Base usage and changes from established forms are presented separately. Includes 23 first-person entries, 70 listed combinations, and a separate third-person reference.

Static HTML, CSS, and JavaScript. Open index.html or serve this directory. GitHub Pages publishes the main branch root.

Pronunciation follows the Learn Like Luke abridged IPA notation.

Content and branding: Learn Like Luke.
